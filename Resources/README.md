# 字体资源

请从 [MiSans 官方下载页面](https://hyperos.mi.com/font/en/download/)下载 MiSans Latin，
将可变字体文件放到以下位置：

```text
Resources/MiSansLatinVF.ttf
```

MiSans 可嵌入 App 使用，但字体文件本身受
[MiSans 字体知识产权许可协议](https://hyperos.mi.com/font-download/MiSans%E5%AD%97%E4%BD%93%E7%9F%A5%E8%AE%B8%E5%8F%AF%E5%8D%8F%E8%AE%AE.pdf)
约束，因此不随本仓库再分发。
